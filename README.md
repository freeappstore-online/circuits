# Circuits

Circuit builder and DC simulator with resistors, LEDs, and nodal analysis

**Live:** https://circuits.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `circuits`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
pnpm test
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
